# Async Network Speed Tester

Асинхронная CLI-утилита на Python для замера скорости скачивания файлов по сети.

Скрипт делает заданное количество GET-запросов к указанному URL **строго последовательно** (в соответствии с ТЗ), дожидается полного скачивания ответа, считает среднее время и выдает итоговую скорость. 

Для оптимизации использования оперативной памяти при скачивании тяжелых файлов реализовано асинхронное потоковое чтение (async streaming chunks) с помощью библиотеки `httpx`. Замеры времени выполняются высокоточным счетчиком `time.perf_counter()`.

## Технологический стек
- Python 3.12+
- `asyncio` — для асинхронного выполнения.
- `httpx` — современный асинхронный HTTP-клиент.
- `uv` — для сверхбыстрого управления зависимостями и виртуальным окружением.

## Установка и запуск

1. Клонируйте репозиторий и перейдите в папку с проектом:
```bash
git clone https://github.com/serker72/etolegko-test-1
cd etolegko-test-1
```

2. Убедитесь, что у вас установлен [uv](https://docs.astral.sh/uv/). Если нет, установите его одной командой (для Linux/macOS):

```bash
curl -LsSf https://astral.sh/uv/install.sh | sh
```

3. Запустите скрипт через `uv run`. Менеджер сам создаст виртуальное окружение и подтянет зависимости (`httpx`) из конфигурации:

```bash
uv run main.py https://ash-speed.hetzner.com/100MB.bin
```

4. Вы также можете изменить количество запросов (по умолчанию 10) с помощью флага `--requests`:

```bash
uv run main.py https://ash-speed.hetzner.com/100MB.bin --requests 5
```

5. Скрипт поддерживает маршрутизацию трафика через HTTP и SOCKS5 прокси-серверы для обхода сетевых ограничений:
```bash
uv run main.py https://ash-speed.hetzner.com/100MB.bin --proxy http://127.0.0.1:8080
# или через SOCKS5:
uv run main.py https://ash-speed.hetzner.com/100MB.bin --proxy socks5h://127.0.0.1:1080
```

## Единицы измерения в результатах

В результатах тестирования скорость выводится в двух стандартах:

* **MB/s (Мегабайт/сек)** — стандартная единица измерения объема файлов.
* **Mbps (Мегабит/сек)** — стандартная единица измерения пропускной способности сети (1 Мегабайт = 8 Мегабит).
